# LICA E-Book 2026

ระบบอ่านหนังสืออิเล็กทรอนิกส์แบบเปิดพลิกหน้า (Interactive Flipbook Reader) สำหรับ **สโมสรไลก้า - LICA CLUB (2026)**

## คุณสมบัติเด่น (Features)
- 📖 **Flipbook Interactive**: พลิกหน้าหนังสือเสมือนจริงด้วย StPageFlip พร้อมเงาตกกระทบและเสียงเปิดกระดาษ
- 🎬 **Integrated Multimedia Video**: ฝังคลิปวิดีโอสัมภาษณ์ในหน้า 7 และหน้า 14 พร้อมโหมดโรงภาพยนตร์ (Cinema Lightbox)
- 🔍 **Zoom & Pan Lightbox**: ดับเบิ้ลคลิกหรือกดปุ่มซูมเพื่อดูรายละเอียดเอกสารระดับ HD
- 🖼️ **Thumbnail Grid View**: ดูตัวอย่างภาพขนาดย่อทั้ง 36 หน้า และเลือกเปิดหน้าได้ทันที
- 🖨️ **Print Support**: ระบบสั่งพิมพ์เอกสารแยกหน้าเดี่ยวหรือพิมพ์ทั้ง 36 หน้า
- 📱 **Responsive Design**: รองรับทั้งจอคอมพิวเตอร์ หน้าจอสัมผัส และสมาร์ทโฟน
- 🎨 **Elegant Light Gray Theme**: ออกแบบสวยงาม ทันสมัย สบายตา พร้อมฟอนต์ IBM Plex Sans Thai

## เทคโนโลยีที่ใช้
- HTML5, CSS3, JavaScript (Vanilla ES6+)
- Tailwind CSS
- StPageFlip Library
- FontAwesome 6
- Google Fonts (IBM Plex Sans Thai)
